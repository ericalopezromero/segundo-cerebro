# Enlaces

Cada categoría empieza con `## Nombre`. Cada enlace es una línea con este formato:
`- [Título](https://direccion.com) descripción opcional`
(Borra estos ejemplos cuando quieras.)

## Ejemplos
- [Wikipedia](https://es.wikipedia.org) — Enciclopedia libre
- [Biblioteca Nacional de España](https://www.bne.es) — Catálogo y recursos digitales
